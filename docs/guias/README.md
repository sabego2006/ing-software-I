# Guías del equipo

Dos guías para Angélica, escritas el 10 de septiembre de 2026 en la semana de preparación
(§6.2 del Plan de Metodología y Preparación). Aquí vive el **código fuente**; lo que se
comparte es el enlace publicado, que se abre desde el celular.

| Guía | Para qué | Enlace publicado |
|---|---|---|
| `tu-semana-en-fusaroute.html` | **Operativa.** Montar el ambiente DEV desde cero, qué decir en el Planning del martes como PO, el circuito Jira → rama → commit → PR, cómo revisar un PR de backend sin saber Java, y el informe del lunes. | https://claude.ai/code/artifact/2ea9fafe-ad59-4ee0-9757-f62bd21f08f1 |
| `por-que-trabajamos-asi.html` | **Formativa.** Por qué existen las ramas y los PR, qué es iterativo–incremental, por qué Scrum sin Daily, los roles en dos capas, hexagonal, y por qué hay tres ambientes. Cada sección cierra con lo que se responde ante el comité. | https://claude.ai/code/artifact/21e54534-36c0-4851-826e-9e681c0460a6 |

Son autocontenidos: se abren con doble clic en cualquier navegador, sin servidor ni
dependencias.

**Al editarlos, hay que volver a publicarlos** — cambiar el archivo aquí no cambia la página
que Angélica tiene abierta. Y hay que republicar **sobre el mismo enlace**, no crear uno
nuevo, para que el que ella ya guardó siga sirviendo.

**Criterio de la guía operativa:** si no le sirve el lunes a las 8 de la mañana, no entra.
Si un comando de ahí no funciona, es un error de la guía y se corrige.
